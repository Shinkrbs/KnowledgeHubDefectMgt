# BUG-004: Knowledge Hub UI [Login]: Cannot log in with newly created accounts

**[Summary]** When a user attempts to log in using the credentials of a newly registered account, the system throws an error and fails to authenticate. However, logging in with the pre-provided testing account works successfully, indicating that the login module functions for existing users but fails to recognize or authenticate new sign-ups.

**[Precondition]** A newly created user account must exist (e.g., an account just created via the SEC-0001 sign-up process).

**[Steps to reproduce]**

1. Launch the Application and verify redirection to the login page.
2. In the login page, fill out the forms (`E-Mail Address`, `Password`) using the credentials of a _newly created_ account.
3. Click the `Sign In` button.
4. Observe the resulting error.
5. (Optional) Clear fields, enter the credentials for the provided testing account, and click `Sign In` to verify the baseline login works.

**[Actual results]** The login attempt for the newly created account ends up in an error, and the user is not authenticated. The provided testing account logs in without any issues.

**[Expected results]** The user with the newly created account should be successfully authenticated and seamlessly redirected to the main page, experiencing the same behavior as the test account.

**[Additional information]** See BUG-003-RECORDING.mp4
(Note: This issue might be linked to BUG-003, potentially indicating that new user data is not being properly saved or synced to the authentication database).

**[Is this Breakage?]** Yes, critical functional breakage. New users are completely blocked from accessing the application.

**[Severity: How does this problem impact the customer/user?]** (7).
Severe functionality and usability issue (Core feature is broken for all new users).

**[Likelihood: How often will a customer/user use this feature/function?]** (9).
Very High (Affects 100% of new users trying to access their accounts for the first time).

**[Repeatability: Is this problem easily reproducible?]** (10).
100% Reproducible for new accounts.

**[Impacted Test Cases]** SEC-0002

**[Impact Sizing (in days)]** Less than a day (Backend/Database verification required).
