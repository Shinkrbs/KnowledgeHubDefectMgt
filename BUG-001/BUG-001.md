# BUG-001: Knowledge Hub UI [Login]: Unrecognized E-Mail and Password error message not displaying

**[Summary]** When a user attempts to log in using invalid credentials, the login correctly fails, but the system does not display an error message or any visual confirmation explaining that the credentials were invalid.

**[Precondition]** None

**[Steps to reproduce]**

1. Launch the Application and verify redirection to the login page.
2. In the login page, fill out the forms (`E-Mail Address`, `Password`) with invalid credentials.
3. Click the `Sign In` button.
4. Observe the UI for any error prompts or feedback.

**[Actual results]** The user fails to sign in using invalid credentials, but there is no visual confirmation or error message indicating that the credentials were invalid.

**[Expected results]** The system should promptly display an error message indicating that the email and password are unrecognized.
