# BUG-003: Knowledge Hub UI [Sign Up]: Missing success confirmation and erratic redirection

**[Summary]** When a user completes the sign-up form and submits their details, the system fails to display a success message or any validation confirming account creation. Instead, the application either abruptly redirects to the sign-in page or unexpectedly lands on an error page, leaving the user unsure if their registration was successful.

**[Precondition]** None

**[Steps to reproduce]**

1. Launch the Application and verify redirection to the login page.
2. At the bottom of the login modal, click the emboldened `Sign Up` text.
3. In the Sign Up modal, fill out all required fields (`E-Mail Address`, `First Name`, `Last Name`, `Password`).
4. Click the `Create Account` button.
5. Observe the UI for validation feedback and note the subsequent page redirection.

**[Actual results]** There is no confirmation or validation message displayed to indicate a successful sign-up. The user is either instantly redirected to the sign-in page without context or encounters an error page.

**[Expected results]** The system should clearly display a success message (e.g., a toast notification or a success screen) confirming that the profile was successfully created before routing the user to the login page or automatically logging them in.

**[Additional information]** See BUG-003-RECORDING.mp4

**[Is this Breakage?]** Yes, missing user feedback and potential routing error/unhandled exception during the onboarding flow.

**[Severity: How does this problem impact the customer/user?]** (6).
Severe GUI, usability, and accessibility issue (Causes severe confusion during account creation, potentially leading to duplicate account attempts or user drop-off).

**[Likelihood: How often will a customer/user use this feature/function?]** (9).
Very High (Every new user must go through this process to access the platform).

**[Repeatability: Is this problem easily reproducible?]** (10).
100% Reproducible
